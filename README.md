# help.pcninja.pro

Source of the Help Pc Ninja remote-support site, served by GitHub Pages at https://help.pcninja.pro

- `index.html` – home (remote support download + other tools)
- `aboutMe/` – about the service
- `aboutMe/contact/` – service request form (embedded Google Form)
- `מחשבים-תמיכה-מרחוק/` – redirect from the old Google Sites address of the home page
- `assets/` – shared CSS/JS and images
